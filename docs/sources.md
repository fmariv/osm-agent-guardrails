# Reference sources (checked 2026-11-23)

Prefer checking these live before changing policy advice. Infrastructure policies, hosts and quotas can change.

## OSM and Overpass

- Overpass official user's manual / public instance model: https://dev.overpass-api.de/overpass-doc/en/preface/commons.html
- Overpass documentation: https://wiki.openstreetmap.org/wiki/Overpass_API
- Overpass QL by examples: https://wiki.openstreetmap.org/wiki/Overpass_API/Overpass_API_by_Example
- OSM downloading and extracts: https://wiki.openstreetmap.org/wiki/Downloading_data and https://wiki.openstreetmap.org/wiki/Planet.osm#Extracts
- OSMF tile usage policy (distinct from Overpass): https://operations.osmfoundation.org/policies/tiles/
- OSMF API usage policy (distinct from Overpass): https://operations.osmfoundation.org/policies/api/
- OSM attribution guidelines: https://osmfoundation.org/wiki/Licence/Attribution_Guidelines
- OSM licensing: https://osmfoundation.org/wiki/Licence

## Agent Skills and editor support

- Open Agent Skills specification: https://agentskills.io/specification
- Cursor skills: https://cursor.com/docs/skills
- Claude Code skills: https://code.claude.com/docs/en/skills
- Codex skills: https://developers.openai.com/codex/skills
- AGENTS.md: https://agents.md/

## Local processing tools

- PyOsmium: https://docs.osmcode.org/pyosmium/latest/
- OSMnx: https://osmnx.readthedocs.io/
- Geofabrik downloads: https://download.geofabrik.de/

**No universal Overpass quota is encoded in the skills.** A historical guideline should not be interpreted as a guaranteed allowance; defer to each instance's current rules and operator guidance.
