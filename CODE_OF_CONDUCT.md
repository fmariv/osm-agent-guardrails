# Code of Conduct

This is an independent community project. We want contributions from mappers,
developers, researchers and infrastructure operators with different levels of experience.

## Expectations

- Treat others with respect. Critique implementations and evidence, not people.
- Be patient with newcomers and ask clarifying questions in good faith.
- Respect the time and resources of volunteer infrastructure maintainers.
- Do not publish private user data, logs, credentials or incident details.
- Avoid harassment, hate speech, intimidation, personal attacks, or doxxing.
- Do not use issue discussions to encourage evading service quotas or bans.

## Scope and reporting

These expectations apply to issues, pull requests, discussions and other
project-managed spaces. Maintainers may edit, hide or remove contributions that
violate them, warn contributors, or restrict participation, depending on severity.

For private reports, contact the repository maintainers using GitHub's private
vulnerability reporting if enabled, or request a private contact channel without
posting sensitive information in a public issue.

This code of conduct is a project-specific policy, not an OSMF policy.
